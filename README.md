## 📖 О проекте

Скрипт автоматически заполняет «отправить позже» (предложку) в мессенджере **MAX** — чтобы вы не забывали отправлять сообщения и не получали по шапке.

> 💡 **Кому подойдёт:** тем, кого пилят за то, что они не отправляют сообщения + в чаты каждый день, и т.д.

⚠️ Проект — **фулл нейрослоп**. Работает как есть, без гарантий и претензий.

## ⚙️ Как это работает

1. Запускаете скрипт.
2. Выбираете **один из двух вариантов** входа.
3. Готово — отправка настраивается автоматически.

### 🔳 Вариант с QR-кодом

Удобно, если **не установлен пароль**.

1. Заходите на **любой сайт-генератор QR**.
2. Скрипт выдаст ссылку вида: https://max.ru/:auth/98a24ba68-dada09-42eda-67bb-228a99d59aec
3. Вставляете эту ссылку в генератор QR.
4. Сканируете QR-код через MAX — и вы в системе.

## 🛠 Требования

- **Python 3.10+**
- Зависимости:

```bash
pip install -U maxapi-python
```
🚀 Быстрый старт
# 1. Клонируем
git clone https://github.com/username/max-auto-sender.git
cd max-auto-sender

# 2. Ставим зависимость
pip install -U maxapi-python

# 3. Запускаем
python main.py

📸 Пример
[1/2] Выберите способ входа:
